## 💡 设计初衷

长期以来，在 Linux（X11 / Wayland）终端环境下一直缺乏一款**好用、美观且深度贴合中文输入习惯**的打字练习工具。虽然终端生态中有诸如 `ttyper` 等优秀的英文跟打软件，但在面对中文输入时往往无能为力：
- **中文输入的特殊性**：中文输入并非简单的“按键即字符”，而是经历拼音/形码组字、候选选词和最终上屏的过程；
- **终端与输入法的割裂**：Linux 终端无法直接探测外部输入法（Fcitx5 / IBus）的弹窗候选与拼音编码，导致传统英文打字工具的逐键匹配逻辑在中文场景完全失效；
- **缺乏专业的数据分析**：中文打字圈有着独特的“字速（WPM）”、“击速（KPS）”、“码长”以及“回改率”等指标体系，缺乏针对性的数据统计与指法分析。

为了给 Linux 开发者与中文打字爱好者提供极致丝滑的跟打体验，**dazitui** 应运而生。它基于 Rust 与 [Ratatui](https://github.com/ratatui/ratatui) 构建，轻量纯粹、毫秒级启动，首创**上屏逐字比对**与 **Rime 方案反查投射**机制，打通在线赛文竞技与本地历史数据分析，让中文打字练习在终端中变得专业、高效且富有乐趣。

## ✨ 特色功能

### 🎯 1. 上屏比对与低延迟实时反馈
- **中文上屏实时核对**：输入法每确认上屏一段文字立即与原文逐字比对，正确/错误即刻渲染高亮，光标平滑跟随。
- **回改精准追踪**：退格修改（Backspace）自动计入回改统计，精确还原真实击打手速与失误代价。
- **复合实时指标**：对照区右下角嵌入 2.0s 滑动窗口复合指标读数 `WPM 120.5 (138) · 击键 5.2 (6.0)`，同时洞悉全局均速与瞬间爆发手速。

### 📚 2. 全方位赛文载入系统
- **📁 本地文件载入**：支持命令行直接传参（`dazitui article.txt`）或在 TUI 内使用交互式文件浏览器（按 `f`）浏览载入。
- **📖 6 套精选内置赛文**：编译期嵌入「常用单字前/中/后五百」与「常用词组前/中/后五百」，支持顺序练习与随机乱序模式（按 `s` 打乱）。
- **🚪 智能组边界门槛**：内置赛文每 10 字/词为一组，当前组全对后方可自动推进到下一组，强化学员单组盲打准确率。
- **✍️ 自由发文**：内置多行文本编辑弹窗（按 `i`），支持自由输入、修改标题与正文，并可一键持久化保存到本地文件。
- **📋 剪贴板发文**：一键从系统剪贴板（按 `p`）读取当前内容并快速开始练习。

### 🌐 3. 52dazi.cn 在线竞技与成绩同步
- **🏆 多级别在线赛文**：原生对接 52dazi.cn，一键载入「极速杯」、「锦标赛（每日生稿赛）」与「键神杯」最新赛文。
- **☁️ 成绩自动上传**：在线赛文跟打完成后自动提交成绩至服务器，实时同步竞技排行。
- **🔗 一键剪贴板分享**：成绩结算后自动格式化生成带排名、速度、击键、码长的分享文本，写入系统剪贴板（支持 OSC 52 跨终端/SSH 协议）。

### ⌨️ 4. 实时虚拟键盘与并击/指法反查引擎
- **🎹 实时虚拟键盘**：支持 **ANSI 60% 标准斜列** 与 **Planck 4x12 直列矩阵** 布局，敲击瞬间全键点亮并伴随 250ms 余温平滑衰减动画。
- **🧩 Rime Schema 深度解析**：内置轻量级 Rime YAML 解析器，支持宏展开与镜像映射，支持将虎码、五笔、小鹤音形、双拼、全拼、空明码并击等汉字反查还原为真实物理按键。
- **⚡ 并击算一击（One-Chord-One-Stroke）**：严格遵循专业打字规范，多键并击统一度量为 1 次击键（1 Stroke），精准计算击速与码长。

### 📊 5. 深度数据统计与分析（SQLite + WAL）
- **💾 轻量非阻塞持久化**：基于 `rusqlite` + WAL 模式，后台异步 Worker 线程持久化流水，主渲染线程 60 FPS 稳定无卡顿。
- **📈 速度演进趋势图 (WPM / KPS)**：支持近 30 场、近 100 场与全历史范围，采用 LTTB（最大三角形三桶）高保真降采样算法绘制 Braille 折线图，叠加 10 场滚动平滑均线。
- **🔥 键位热力图**：采用对数平滑归一化算法（Logarithmic Normalization）阶梯着色，支持「方案反查投射」与「物理按键捕获」双视角切换。
- **❌ 高频错字 / 错词排行榜 Top 50**：结合内置赛文原生词边界与轻量 `jieba-rs` 中文分词引擎，精准定位高频失误词汇与薄弱单字。

### 🎨 6. 现代化主题与高度可定制 UI
- **🌈 8 款内置经典主题**：Catppuccin Mocha、Cyberpunk 赛博霓虹、Nord、Dracula、Gruvbox Dark、Rosé Pine、Kanagawa、One Dark。
- **✨ 现代化视觉规范**：全界面圆角边框（Rounded Borders）、动态焦点高亮、多段结构化标题与胶囊按键提示。
- **📐 布局与字号自适应**：对照区/跟打区垂直比例自由调节（30% - 80%），支持粗体开关与 Kitty 终端 OSC 50 字号增强。

## 🚀 快速开始

### 📦 安装与编译

确保已安装 Rust 工具链（1.85+，Edition 2024）：

```bash
# 克隆仓库
git clone https://github.com/JackTheMico/dazitui.git
cd dazitui

# 编译并运行
cargo run --release

# 或安装到系统 Cargo bin 目录
cargo install --path dazitui
```

### 🎮 使用方式

```bash
# 1. 默认无参启动（自动载入「常用单字前五百」）
dazitui

# 2. 载入本地文本文件练习
dazitui ./articles/test.txt

# 3. 命令行查看版本
dazitui --version
```

> **💡 终端建议**：推荐使用支持 24-bit TrueColor 与 Kitty 键盘增强协议的现代终端（如 Alacritty、Kitty、WezTerm、Foot、Ghostty 等），以获得最佳视觉效果与快捷键体验。

## ⌨️ 快捷键指南

### 🎯 跟打 / 就绪主界面

| 快捷键 | 功能说明 |
| :--- | :--- |
| `字符键` | 输入法输入中文字符上屏跟打（自动开始计时） |
| `Backspace` | 回改删除上屏字符（计入回改统计） |
| `Tab` | **暂停跟打**并切入功能栏；在就绪态时展开/聚焦功能栏 |
| `Esc` | 在暂停态或就绪态下聚焦跟打区恢复打字 |
| `Ctrl + Q` / `q` | 退出程序（跟打未开始时 `q` 可直接退出） |
| `Ctrl + Enter` | 提前结束跟打并结算成绩 |

### 🧭 功能栏与赛文选择（就绪 / 暂停态）

| 快捷键 | 菜单项 | 功能说明 |
| :--- | :--- | :--- |
| `f` | 载入文件 | 打开文件浏览器选择本地赛文（`j`/`k` 导航，`Enter` 载入） |
| `b` | 内置赛文 | 打开内置套题浏览器（`s` 切换乱序/顺序，`Enter` 载入） |
| `i` | 自由发文 | 打开多行编辑器编辑赛文（`Ctrl+S` 保存，`Ctrl+Enter` 载入） |
| `p` | 剪贴板发文 | 一键读取系统剪贴板文本并载文 |
| `1` | 极速杯 | 载入 52dazi.cn 极速杯在线赛文 |
| `2` | 锦标赛 | 载入 52dazi.cn 锦标赛在线赛文（每日生稿赛） |
| `3` | 键神杯 | 载入 52dazi.cn 键神杯在线赛文 |
| `s` | 数据统计 | 打开全局历史统计视图（WPM 趋势 / 热力图 / 错字榜） |
| `o` | 外观设置 | 打开设置视图（主题、比例、键盘模式、输入法等） |
| `l` | 登录账号 | 打开 52dazi.cn 账号登录弹窗 |

### 📊 成绩视图（跟打完成后）

| 快捷键 | 功能说明 |
| :--- | :--- |
| `Enter` / `r` | 重新开始跟打当前赛文（离线/内置赛文可用） |
| `s` | 直达全局数据统计视图 |
| `Esc` | 返回主界面就绪态 |
| `Ctrl + Q` | 退出程序 |

### 📈 统计视图

| 快捷键 | 功能说明 |
| :--- | :--- |
| `1` / `2` / `3` | 切换 **速度趋势图** / **按键热力图** / **错字错词排行榜** |
| `Tab` / `Shift+Tab` | 循环切换子 Tab |
| `r` / `s` | 切换趋势图指标（WPM 词速 ↔ KPS 击速） |
| `v` | 切换趋势图时间跨度（近 30 场 ↔ 近 100 场 ↔ 全部历史） |
| `L` | 切换键位热力图布局（标准斜列 ANSI ↔ 直列矩阵 Planck） |
| `m` | 切换热力图视角（方案反查投射 ↔ 纯物理击键） |
| `t` | 切换排行榜焦点（高频错字榜 ↔ 高频错词榜） |

| `Esc` / `q` | 退出统计视图返回主界面 |

### ⚙️ 设置视图

| 快捷键 | 功能说明 |
| :--- | :--- |
| `↑` / `k` / `↓` / `j` | 上下移动设置焦点（主题 / 比例 / 粗体 / 虚拟键盘 / 方案反查 / 输入法名称） |

| `Esc` / `q` | 保存并退出设置视图 |

## 🛠️ 配置与存储说明

`dazitui` 严格遵循 Linux XDG 规范存储配置文件与数据：

- **配置文件**：`~/.config/dazitui/settings`（极简键值对格式）
- **本地统计数据库**：`~/.local/share/dazitui/stats.db`（SQLite 3 WAL 模式）
- **52dazi Token**：`~/.config/dazitui/token`
- **自定义方案与码表目录**：优先检索 `~/.config/dazitui/schemes/` 及 `~/.local/share/fcitx5/rime/`
