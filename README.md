# dazitui
linux上没有好用的中文打字练习工具，所以做了这个用来练习打字。 
## 设计
### 界面
- 可以参考ttyperk: https://github.com/max-niederman/ttyper，
- 大体分成上下两部分，上面给出练习用的文字，用户打对和打错时用不同的颜色渲染字体；下面是用户的跟打区，用户在这里使用自己的输入法进行跟打练习。
- 左侧是一个可以收起的功能栏，让用户可以通过这里来选择文件来载文，或进行52dazi.cn的登录。
- 底部要有一个快捷键提示的bar，提示一些常用的功能键，比如：发文，重打，载入极速杯赛文等。
### 离线功能
1. 用户可以用命令：dazitui `文件名`，将文件里面的文字加载到dazitui中，开始打字练习。
2. 用户跟打时，实时统计用户的回改，统计哪些字词打错；用户打完后，可以给出打字的WPM，以及打错的字词，按键的频率。
### 在线功能
1. 用户可以登录到：http://www.52dazi.cn/
2. 用户可以选择载入：极速杯赛文，锦标赛文，键神杯赛文，并进行跟打练习。用户跟打完后，其成绩能上传至：http://www.52dazi.cn/
3. 跟打完成后，将 http://www.52dazi.cn/ 返回的数据放到系统剪贴板里，方便用户进行分享。

## 实现
1. 使用 rust 与 Ratatui完成开发。
