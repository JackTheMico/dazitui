# 单字练习目标门槛与单组冲刺统计架构

为满足"单字练习专项冲刺、必须达到目标手速或打字速度才允许进入下一组"的刻意练习需求，确立目标门槛与单组冲刺统计的架构决策。

## 1. 范围与指标定义

- **适用范围**：仅针对**内置单字赛文**（如常用单字前/中/后五百、空明码一击字）生效；词组赛文及长文保持既有全对放行逻辑不变。
- **核心指标**：
  - **目标击键**（Target KPS）：以每秒击键次数（含并击算一击）衡量。
  - **目标速度**（Target WPM）：以每分钟正确字数衡量。
- **双目标关系（OR 逻辑）**：
  - 用户可独立设置两项指标（`0.0` / `0` 表示不设限）；
  - 若同时配置两项目标，组末判定采取 **OR 逻辑**——满足 `实际 KPS >= 目标 KPS` **或** `实际 WPM >= 目标 WPM` 即可放行进下一组；仅在两项目标均未达成时阻断放行。

## 2. 单组独立考核与首键起跑时钟

- **单组独立窗口**：不采用整局均值或全局累计指标，严格以当前组（如 10 字）为独立度量窗口。
- **起止点判定**：
  - 从用户敲入当前组第 1 键（或首字）起开始单组计时；
  - 组内所有字符全部正确上屏且到达组末时进行放行判定。
- **重置待机态**：若未达标触发重打，本组输入清空回退到组首，单组计时器处于待机暂停状态，直到用户敲下重试的第 1 键才正式开始下一轮计时，避免用户调整呼吸时平白损失耗时。

## 3. 未达标重打与失败尝试统计剥离（纯净通关数据）

- **自动重打（重打当前组）**：
  - 组末未达标时，系统立即清空本组已上屏内容，并在状态栏保留未达标差距反馈（如 `未达标: 45/60 WPM, 4.2/6.0 击键 — 已重置，请重打`），待下一次首键敲击时自动隐去。
- **失败数据剥离**：
  - **决策**：因未达标而重打的失败尝试数据（时间、按键流水、事件），**不计入**整局最终成绩与数据库持久化记录。
  - **权衡理由**：单字目标练习属于专项速度冲刺。若将失败重打的停滞耗时全量算入物理总耗时，可能导致整局平均速度被严重拉低（如跌至 10 WPM），破坏历史速度折线图与用户的正向练习反馈；最终成绩只呈现所有成功通过组的纯净达标表现。

## 4. 配置入口与持久化

- **双入口体系**：
  - **设置视图**（全局持久化）：在 `Settings` 中新增 `target_kps: f64` 与 `target_wpm: u16`，保存至 `settings.json`；提供步进切换档位；
  - **预览弹窗**（即时调整）：在内置单字赛文预览弹窗中显示当前目标门槛，并支持快捷键（`k` 切换目标击键、`w` 切换目标速度）快速轮转预设档位。
