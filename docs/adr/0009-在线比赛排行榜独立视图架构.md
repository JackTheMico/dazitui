# 0009-在线比赛排行榜（独立视图）架构

- 状态：提案（经 `/grill-me` 多轮质疑后成型，2026-08-30）
- 关联：ADR-0002（逆向协议，含 `getCompetitionRank` 端点规格）、CONTEXT.md（在线赛文 / 功能栏 / 统计视图术语）

## 1. 背景与问题

用户希望在应用内查看 52dazi 三个在线赛文（极速杯 / 锦标赛 / 键神杯）的**实时比赛成绩排行榜**。

术语冲突：统计视图已有一个「错字错词排行榜」（`error_ranking`，本地历史失误榜）。本次的「在线比赛排行榜」是**完全不同**的概念（线上全网成绩、按天分期）。UI 文案与代码命名必须区分，避免用户与维护者混淆。

数据可行性已逆向确认（见 ADR-0002 增补）：`POST /Api/Rank/getCompetitionRank` 存在、可免登录调用、期次 = 当天日期 `YYYY-MM-DD`、响应含 `rankResult` 与 `myRankResult`。

## 2. 决策（grill 结论）

1. **数据来源**：`getCompetitionRank`。期次 = 当天日期，与 `getContent` 当日赛文严格对应——"绑定同期"自然成立，无需从 `getContent` 响应额外取期次（其响应本就不含期次字段，已验证）。
2. **位置**：**不在窄功能栏列内渲染榜单表**。在功能栏新增「在线排行榜」菜单项，打开**独立全屏视图**；三个比赛以 **Tab**（极速杯 / 锦标赛 / 键神杯）切换。
   理由：功能栏本质是导航菜单，收起时宽度为 0；榜单表需可滚动空间，塞进侧栏信息密度过低。
3. **刷新与并发**：进入视图即拉取一次；按 `R` 手动刷新。拉取在**后台 worker**（参照 `DbWorker` 模式）非阻塞执行，结果经 channel 回主线程渲染——现有 online 栈是同步 `ureq`，直接在主循环调用会冻结 TUI。
   - 未登录仍可看公开榜（接口免登录）；仅"我方高亮"不可用。
4. **展示列**：
   - **v1 固定默认列**：排名 / 用户名 / 速度(WPM) / 输入法。窄屏可读、一眼看完。
   - **v2（增量）**：可配置列——码长 / 键准 / 键数 / 回改 / 打词率 / 门派 / 武力值 / 设备 / 用时。用户选定"可配置列"，但 v1 先交付默认集，把列选择 UI + 持久化留作下一增量，避免首版范围膨胀。
5. **我方位置**：用响应 `myRankResult`（登录后服务端返回当前用户整行）高亮我的行，并在视图顶部显示「我第 N 名 / 共 M 人」。未登录时 `myRankResult` 为 `[]`，不显示高亮与名次条。
6. **降级策略（分因）**：
   - 未登录 → 照常显示公开榜，仅无我方高亮；
   - 从未下载该比赛赛文 → 直接拉当天榜（期次=今天，无需先载文）；
   - 网络失败 → 显示错误提示 + 重试键（`R`）；不崩溃主循环。
7. **缓存**：内存缓存最近一次成功结果，重入即时显示、断网可看上次结果；**不持久化到磁盘**（避免过期数据误导）。

## 3. 端点规格（摘要，权威见 ADR-0002）

请求（AES-128-CBC，公共字段 + 可选 token）：
`{ snum:"2026-08-30", competitionType:0|2|4, deviceType:0, pagesize:30, currentPage:1 }`

响应：
`{ error, msg:{ rankResult:Row[], myRankResult:Row[], total, textTitle, textLength, content, winnerMusicUrl } }`

Row 可渲染字段：`rank, username, speed, keystrokes(击键), maChang(码长), jianZhun(键准), jianShu(键数), huiGai(回改), daCi(打词率), typingTime(用时), inputMethod(输入法), from(设备), sectName(门派), force(武力值), levelName, userId, id`。
忽略：`img / musicUrl / showSectName(HTML) / *Color` 等不可渲染字段。

## 4. 影响与工作量

- `dazitui-core/src/online/`：新增 `get_competition_rank` 纯函数解析 + `ApiClient::get_competition_rank` 方法，复用现有 AES 与 client 基础设施（无需新依赖）。
- 后台拉取：新增 rank worker（类 `DbWorker`），承载非阻塞网络调用，结果经 channel 回主线程。
- `dazitui/src/main.rs`：
  - 功能栏新增「在线排行榜」菜单项；
  - 新增排行榜视图（独立 `AppState` 或复用浏览态），三 Tab 渲染；
  - `R` 刷新键；我方行高亮；顶部「我第 N 名 / 共 M 人」；降级空态。
- 命名：代码层用 `online_rank` / `OnlineRank*` 前缀，与统计视图 `error_ranking` 显式区分。

## 5. 风险与权衡

- **期次严格按天**：跨天 / 历史榜默认不可见（与官方 Web 一致，可接受）；若未来需历史榜，改 `snum` 即可，不在 v1 范围。
- **服务端限频未知**：进入即拉 + 手动刷新足够克制；若实测被限频，再加节流（如最小刷新间隔）。
- **逆向端点脆弱性**：`getCompetitionRank` 为逆向所得，52dazi 改版需同步更新 ADR-0002；解析对未知字段做宽容处理（忽略多余键）。

## 6. 验收标准

- 功能栏出现「在线排行榜」，进入后默认显示当天极速杯榜（免登录可看，含真实数据）。
- 三 Tab 切换正常；`R` 重新拉取；登录后我方行高亮并显示「我第 N 名 / 共 M 人」。
- 网络断开时显示错误 + 重试提示，主循环不冻结。
- 代码/文案无与统计视图「错字错词排行榜」的命名混淆。
