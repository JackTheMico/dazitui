# 编码提示（遍码提示）功能架构

为满足"跟打时直接在对照区看到每个字词的最优输入编码、降低学习与上屏成本"的需求，确立编码提示功能的架构决策。该提示复用既有的方案反查基础设施，在对照区把待输入编码渲染到对应字词上方，并随跟打推进自动隐藏已打部分。

## 1. 范围与术语

- 新增设置开关 **遍码提示**（布尔，默认关闭），覆盖**全部赛文类型**——内置、离线、自由发文、剪贴板发文、在线赛文。首版不做范围收窄。
- 渲染物命名为 **编码提示**（code hint），与既有 **方案反查**（物理键位逆向，供热力图）明确区分：编码提示显示的是"用户待敲的编码"（拼音/形码字母或并击逻辑码元），而非物理键位。形码/拼音下二者一致；并击下逻辑码元（如 `wCs`）与物理并击键不同。

## 2. 对照区排版架构：手动双行词格（刻意偏离 Paragraph+Wrap）

因要求覆盖长文/在线赛文（自动折行），而 Ratatui `Paragraph`+`Wrap` 会逐字符折行，导致"提示行"与"正文行"各自错位、提示再也无法对齐其下方字词。故**不采用 Paragraph 自动折行**，改为手动排版：

- 开启编码提示时，按终端宽度**以"词"为最小换行单元**逐词打包为若干"词行"；每个词行由上下两行构成——上行 = 各词的编码提示，下行 = 对应字词正文；
- 打包边界与 `segmenter` 的 `WordIndex` 词边界一致，保证提示永远对齐其下方字词，且提示行与正文行折行点完全相同（锁步）；
- 每个词格预留固定"提示列宽"（默认 4 列），CJK 双宽与超宽编码（如并击 `wCs`）在打包阶段统一截断/居中处理；
- 同一套布局服务内置赛文（单字/词组分页）与长文，从根本上消除折行错位这一主要技术风险。

> 这是相对"直接用 Paragraph 渲染提示行+正文行"的刻意偏离：后者实现快但长文错位无解，故选前者。

## 3. 最优编码算法（始终取最少击数）

对每个词组单位（或单字）计算并展示"按键最少"的编码：

- **整词优先**：若 `SchemeDict::get_primary_code(word)` 命中，且其击数（`calculate_code_strokes`）≤ 词内各字逐字编码击数之和，则展示整词码；
- **逐字回退**：否则对词内每字取 `get_primary_code` 拼接展示；
- **多编码词条**（`Vec<String>`）：取 `calculate_code_strokes` 最小者；
- **并击方案**：经 `ChordAlgebra::decompose_code` 得逻辑码元序列（如 `wCs`），按"并击=1 击"的度量（见词汇表·击键）比较整词码元数与逐字码元数，取较少者；码元超宽时按提示列宽截断/居中；
- **未登录词/字（OOV）**：无整词码则逐字；字亦 OOV 则该字不显示提示（留空）；
- **复用与缓存**：复用已常驻的 `App.scheme_dict`（`dazitui/src/main.rs:668` / `reload_scheme_dict` `:855`），在载文与方案重载时**预计算一次**并缓存，绝不在每帧 `original_line` 重算。

## 4. 可见性规则：自动隐藏已打部分

- 编码提示随跟打推进动态显隐：仅当某字词**尚未被正确提交**时显示其上方提示；一旦该字词被正确上屏（经 `session.original_status()` 判定，见 `session.rs:566`），其提示即消失；
- 回改导致该字重新变为未提交时，提示随之重现；
- 该规则对全部赛文类型一致生效，避免剧透已完成部分。

## 5. 设置接入

- `Settings` 增加 `code_hint: bool`（默认 `false`），save/load 增加 `code_hint=` 行；
- 设置视图增加一行（新增 `FOCUS_CODE_HINT` 焦点），套用既有布尔开关模式（参照 `bold`：`settings.rs:341/528`、`main.rs:234/928/934`）；
- 若方案未配置词典（仅 `.schema.yaml` 规则而无 `.dict.yaml` 词条），开启时对照区提示区显示"方案未配置/无词典"占位，而非空白或报错。

## 6. 与既有模块关系

- **复用**：`SchemeDict`（`scheme.rs`）、`WordIndex`/`Segmenter`（`segmenter.rs`）、`session.original_status()`（`session.rs:566`）、`App.scheme_dict` 加载通道、并击 `ChordAlgebra` 与实时键盘高亮（ADR 0006）；
- **新增**：`dazitui-core` 内新增编码提示预计算（建议 `scheme.rs` 增 `build_code_hints` 或在 `session` 层缓存 hint 映射）；`dazitui` 对照区双行词格渲染（替换/扩展 `build_word_spans`/`original_line` 在编码提示开启时的路径）。
