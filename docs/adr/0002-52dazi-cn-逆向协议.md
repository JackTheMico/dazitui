# 52dazi.cn 使用逆向协议对接

52dazi.cn 无公开 API 文档，其 SPA 前端（www.52dazi.cn）实际调用 `http://www.jsxiaoshi.com/index.php`（ThinkPHP）。请求体需 AES-128-CBC 加密（key=`c9ec834c80f77237`，iv=`db4d6bfde3057dca`，ZeroPadding），请求字段带 `token`/`version`；响应为明文 JSON。登录 `POST Api/User/login`（username+password）返回 token；载入赛文 `Api/Text/getContent?competitionType=&snumflag=1`（需登录；极速杯=0、锦标赛=2、键神杯=4）；赛文列表/随机文 `Api/Text/getTextList`、`getRandomText`（无需登录）；成绩上传 `Api/Rank/uploadResult`。注意：锦标赛为生稿赛，每天仅可载入一次且不支持重打。在线功能（第二阶段）须遵循此协议。
