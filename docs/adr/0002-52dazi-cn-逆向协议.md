# 52dazi.cn 使用逆向协议对接

52dazi.cn 无公开 API 文档，其 SPA 前端（www.52dazi.cn）实际调用 `http://www.jsxiaoshi.com/index.php`（ThinkPHP）。请求体需 AES-128-CBC 加密（key=`c9ec834c80f77237`，iv=`db4d6bfde3057dca`，ZeroPadding），请求字段带 `token`/`version`；响应为明文 JSON。登录 `POST Api/User/login`（username+password）返回 token；载入赛文 `Api/Text/getContent?competitionType=&snumflag=1`（需登录；极速杯=0、锦标赛=2、键神杯=4）；赛文列表/随机文 `Api/Text/getTextList`、`getRandomText`（无需登录）；成绩上传 `Api/Rank/uploadResult`；**比赛排行榜 `POST Api/Rank/getCompetitionRank`（无需登录）**。注意：锦标赛为生稿赛，每天仅可载入一次且不支持重打。在线功能（第二阶段）须遵循此协议。

## 比赛排行榜端点（getCompetitionRank，2026-08-30 逆向确认）

- 请求体（AES-128-CBC 加密，复用公共字段 `from/version/subversions/timestamp`，登录时附带 `token`）：
  `{ "snum": "2026-08-30", "competitionType": 0|2|4, "deviceType": 0, "pagesize": 30, "currentPage": 1 }`
  - `snum` = **当天日期 `YYYY-MM-DD`**，即排行榜的「期次」键；与 `getContent` 当日返回的赛文严格对应（极速杯/键神杯每日一篇，锦标赛为生稿）。
  - `competitionType`：极速杯=0、听打赛=1、锦标赛=2、幻影杯=3、键神杯=4（本应用仅用 0/2/4）。
  - `deviceType: 0` 表示 PC 端榜单。
  - `pagesize`/`currentPage` 分页，默认 30/1。
- 响应：`{ "error": 0, "msg": { "rankResult": Row[], "myRankResult": Row[], "total": N, "textTitle": "...", "textLength": 369, "content": "...", "winnerMusicUrl": "..." } }`
  - `rankResult`：榜单行数组；`total`：该期总提交数。
  - `myRankResult`：**登录后由服务端返回当前用户整行（数组，命中时长度 1），未登录为空数组 `[]`**——用于高亮「我的名次」，无需客户端按用户名匹配。
  - `textTitle`/`textLength`/`content`：当期赛文元数据，可作视图上下文头。
- Row 关键字段（TUI 可渲染）：`rank, username, speed(速度/WPM), keystrokes(击键), maChang(码长), jianZhun(键准%), jianShu(键数), huiGai(回改), daCi(打词率%), typingTime(用时 mm:ss.mmm), inputMethod(输入法), from(设备/客户端名), sectName(门派), force(武力值), levelName, userId, id`。
- Row 应忽略字段（TUI 不可渲染）：`img`(头像 URL)、`musicUrl`/`winnerMusicUrl`(音频)、`showSectName`(含 HTML 的富文本)、`nameColor`/`sectColor`/`specialTitleColor`(颜色) 等。
- 期次严格按天，历史日期榜可通过改 `snum` 查询，但本应用 v1 仅取当天。
