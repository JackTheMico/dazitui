# 0017. 牛杯（ox-cup）使用逆向协议对接与群赛架构

- **状态**: Accepted
- **日期**: 2026-09-24

## 背景与上下文

`dazitui` 在线功能原先支持 52dazi.cn 以及官方比赛「虎码杯」（`race.tiger-code.com`）。
除虎码官方生稿赛外，打字交流社区中长期存在另一项高活跃度的每日公共打字赛事——「牛杯」（又称 ox-cup）。
通过对官方客户端「虎魄跟打器（Hyper）」Linux 编译产物 `虎魄跟打器` 的逆向解析与实时接口发包验证，完全确认了牛杯的服务端通信协议与成绩流转机制：
1. **赛文获取**：无需账号登录，通过公开 API 直接按北京时间拉取今日赛文；
2. **排行榜获取**：无需账号登录，通过小稽 QQ 机器人汇聚 API 查询当日排行榜；
3. **成绩上榜**：服务端无直连 HTTP 成绩上传接口，成绩由打字用户完成练习后将格式化的文本发送到打字 QQ 群，由群内机器人解析入库。

为了向 Linux 终端打字爱好者提供完整的竞赛练习生态，决定将「牛杯」接入 `dazitui`。

## 协议技术规范

### 1. 赛文拉取端点
- **网关地址**：`http://tiger-code.com:8000`
- **请求方式**：`GET /ox-cup/article/{YYYY-MM-DD}`
- **说明**：免认证公开端点，按日期查询。
- **成功响应**：
  ```json
  {
    "code": 1,
    "message": "success",
    "data": {
      "id": 223,
      "title": "2026-09-24 牛杯赛文",
      "content": "公司年会上，老板激动地抽取特等奖...",
      "date": "2026-09-24",
      "length": 141,
      "hash": "d7bbd30c"
    }
  }
  ```

### 2. 排行榜端点
- **网关地址**：`http://123.60.58.190:6190`
- **请求方式**：`GET /api/nb_scores?date={YYYY-MM-DD}`
- **说明**：免认证公开端点，返回小稽 QQ 机器人从各大打字群汇总的成绩列表。
- **成功响应**：
  ```json
  {
    "status": "success",
    "message": "获取成功",
    "data": {
      "date": "2026-09-24",
      "count": 18,
      "scores": [
        {
          "user_id": "1311804709",
          "user_name": "小铭同学",
          "speed": 283.18,
          "hit_rate": 9.04,
          "kpw": 1.91,
          "accuracy": 97.87,
          "time": null,
          "corrections": 2,
          "word_ratio": null,
          "group_name": "聚贤阁",
          "group_id": "12941287",
          "timestamp": "2026-09-24T11:26:06.931779"
        }
      ]
    }
  }
  ```

### 3. 成绩打卡格式
牛杯赛文在打字群内约定段号为 `第666段`。跟打完成后，系统生成兼容小稽等主流 QQ 机器人的打卡分享文本写入系统剪贴板：
> `第666段 速度{speed} 击键{kps} 码长{key_length} 键准{accuracy}% 回改{edits} 回车0 退格{backspace} 字数{total_chars} 键数{strokes} 时间{time} 打词{word_ratio}% 凭证{hash} dazitui`

## 架构与影响

1. **赛文与重打语义**：牛杯作为 `TextSource::OxCup`，属于免账号普通在线赛文，允许自由重打（打完或中断时支持按 `r`/`Enter` 重新开始），每次完成均刷新剪贴板打卡文本。
2. **模块拆分**：在 `dazitui-core::online::oxcup` 下实现 `OxCupClient`（负责赛文与榜单获取）及 `share.rs`（负责打卡格式化）。
3. **主界面与快捷键**：功能栏「在线比赛」组中新增「牛杯」，分配快捷键 `n` / `N`。
4. **排行榜视图**：通用排行榜视图中扩展第 5 个 Tab `[牛杯]`，群组名（`group_name`）映射至现有表格的门派/输入法列统一展示。
